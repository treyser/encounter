# Сутички — розширення для Owlbear Rodeo

Генератор сутичок за складністю з бестіарію на 60 монстрів. Підбирає групу
під рівень партії й одразу створює ворогів на мапі на потрібній відстані
від героїв.

## Спершу — бібліотека токенів

Розширення створює ворогів з тих картинок, які ти йому показав.
Постав токен монстра на сцену, **ПКМ → «Бестіарій»**, обери зі списку,
хто це, і натисни «Запамʼятати токен». Картинка збережеться в метаданих
кімнати, і далі монстр доступний генератору.

Робиться один раз на кімнату. Генератор бере лише тих, кого вже привʼязано,
тож можна почати з десятка й доповнювати.

## Як генерувати

Іконка «Сутички» вгорі зліва. Вкажи кількість гравців і рівень, обери
складність і, якщо треба, категорію монстрів. «Згенерувати» підбирає групу,
«Спавнити» ставить її на мапу.

Відстань задається в клітинках: «не ближче» тримає ворогів подалі від
героїв, «не далі» не дає розкидати їх по всій мапі. Позиції випадкові,
прилипають до сітки, не накладаються одна на одну і не виходять за межі
мапи.

Однакових монстрів пронумеровано, під кожним підписано ХП і КД.
«Прибрати ворогів зі сцени» видаляє всіх, кого створило розширення.

## Чому не напряму з Kobold+

У Kobold+ немає API, а його дані лежать у localStorage власного домену —
браузер не дає стороннім сайтам туди зазирати. Зате формули відкриті:
пороги досвіду за рівнем і множники за кількістю ворогів перенесені
в `src/balance.js`, тож розрахунок збігається з тим, що показує сайт.

## Як влаштовано

| Файл               | Що робить                                            |
| ------------------ | ----------------------------------------------------- |
| `src/bestiary.js`  | 60 монстрів: CR, XP, КД, ХП, категорія.              |
| `src/balance.js`   | Пороги складності, множники, підбір групи.           |
| `src/place.js`     | Межі мапи, пошук вільних клітинок, відстань.         |
| `src/menu.js`      | Привʼязка токена до монстра.                         |
| `src/main.js`      | Вікно генератора і створення ворогів.                |

Підбір групи перебирає шістсот випадкових комбінацій і лишає найближчу
до цільового досвіду — так сутички щоразу різні, чого не дав би жадібний
алгоритм.
